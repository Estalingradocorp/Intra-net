Las personas usan la pantalla blanca para:

Iluminación para llamadas de zoom

Para videollamadas! No tengo anillo de luz, pero sí dos pantallas. Puedo usar una para iluminar mi cara!

Copiar dibujos

Necesito un fondo blanco brillante debajo de mi papel para copiar un dibujo mas facilmente.

Comprobar el monitor

Para revisar el monitor y encontrar píxeles muertos con facilidad.

Limpiar el monitor

Lo uso para limpiar el monitor, es fácil ver la suciedad. También para calibrar colores entre diferentes pantallas.

Luz para leer

Para tener una fuente de luz para lectura nocturna, cuando el interruptor está demasiado lejos.

Atrapar moscas

Lo uso para atrapar mosquitos y moscas, al ser estos atraídos a la pantalla blanca.
